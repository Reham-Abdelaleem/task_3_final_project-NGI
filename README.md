# Explore The World

An interactive travel website that showcases popular destinations with a simple slider.

## Features

- Hero section with a call-to-action
- Destination slider with previous/next buttons and navigation dots
- Detailed info for each city: country, continent, famous food, famous place, and language
- "Explore More" button that shows a short message about the city
- Responsive layout for mobile screens

## Destinations

- Paris, France
- Tokyo, Japan
- Rome, Italy
- Cairo, Egypt

## Built With

- HTML5
- CSS3
- JavaScript (vanilla)
